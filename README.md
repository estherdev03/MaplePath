# MaplePath AI 🍁

An AI-powered Alberta immigration copilot that helps users assess eligibility, track immigration journeys, monitor policy updates, forecast invitation opportunities and generate personalized action plans.

Built with LangGraph, FastAPI, PostgreSQL, pgvector, OpenAI, and XGBoost.

## Key Features
- CRS Score Calculation
- Eligibility Assessment
- Alberta Policy RAGg
- AI Immigration Advisor
- Draw Forecasting
- Journey and Deadline Tracking
- Personalized Action Plans
- Event-Driven LangGraph Workflows
